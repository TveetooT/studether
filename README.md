# 🏠 Livether — бот для поиска соседей

**Livether** — это Telegram-бот для поиска идеального соседа по совместной аренде жилья. Бот помогает студентам и молодым людям находить сожителей в своём городе, заполнять анкету, просматривать анкеты других пользователей и обмениваться лайками.

---

## 📌 Функциональность

- ✅ **Регистрация и авторизация** – пользователь создаётся автоматически при первом запуске.
- 📝 **Заполнение анкеты** – пошаговое заполнение профиля (имя, возраст, город, описание, пожелания).
- 🔍 **Поиск соседей** – умный алгоритм показывает анкеты из того же города, исключая уже просмотренные.
- ❤️ **Лайки и взаимные совпадения** – при взаимном лайке обе стороны получают уведомление с контактами.
- 📊 **Рейтинг показываемости** – анкеты распределяются по приоритету на основе времени последней активности и количества просмотров.
- ⚙️ **Редактирование профиля** – можно изменить любое поле анкеты.
- 🛡️ **Административная панель** – управление пользователями, бан, удаление анкет, статистика.
- 📈 **Публичная статистика** – информация о количестве пользователей, анкет, просмотров, лайков и топе городов.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/livether-bot.git
cd livether-bot
```

### 2. Установка зависимостей

```bash
python -m venv venv
source venv/bin/activate   # Linux/Mac
# или
venv\Scripts\activate      # Windows

pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Создайте файл `.env` или установите переменные окружения в Render:

```
TELEGRAM_TOKEN=ваш_токен_бота
SUPABASE_URL=https://ваш_проект.supabase.co
SUPABASE_KEY=ваш_publishable_ключ
WEBHOOK_URL=https://ваш_сервис.onrender.com/webhook
ROOT_CODE=секретный_код_администратора
```

### 4. Настройка базы данных (Supabase)

1. Создайте проект в [Supabase](https://supabase.com).
2. Выполните SQL-скрипт из файла `recreate_database.sql` (создаёт таблицы `users`, `views` и функцию `get_unseen_users`).
3. Добавьте индексы для ускорения запросов.

### 5. Запуск бота (локально)

```bash
python app.py
```

Для продакшена разверните на Render и установите вебхук автоматически.

| `age` | INTEGER | Возраст |
| `city` | TEXT | Город поиска |
| `region` | TEXT | Регион |
| `univer` | TEXT | Учебное заведение |
| `about` | TEXT | О себе |
| `requirements` | TEXT | Пожелания к соседу |
| `form` | TEXT | 'true'/'false' – заполнена ли анкета |
| `action` | TEXT | Текущее состояние диалога |
| `root` | TEXT | 'true'/'false' – администратор |

| Поле | Тип | Описание |
|------|-----|----------|

## 🔧 Админ-команды (в Telegram)

Только для пользователей с `root = 'true'`:

| Команда | Действие |
|---------|----------|
| `cmd_deleteform <user_id>` | Удалить анкету пользователя |
| `cmd_cleardata` | Удалить все данные из БД (требует подтверждения) |
| `cmd_recreatedb` | Пересоздать структуру БД (требует подтверждения) |
| `cmd_selftest` | Запустить диагностику бота |

## 📈 Рейтинг показываемости

Анкеты сортируются по приоритету на основе двух факторов:
- **Время последней активности** (`last_active`) – чем свежее, тем выше приоритет.
- **Количество просмотров** (`views_count`) – чем меньше, тем выше приоритет.

Формула веса:
```
weight = (days_since_active + 1) / (views_count + 1)
```

При поиске бот выбирает одну анкету случайным образом, но с вероятностью, пропорциональной весу каждой анкеты.

## 🛠️ Разработка и расширение

- **Добавление новых полей в анкету:** измените список `Actions`, словари `Phrases` и `FieldLimits`, а также SQL-таблицу `users`.
- **Добавление новых городов:** обновите файл `regions.py`.
- **Изменение логики поиска:** модифицируйте функцию `get_unseen_form` и SQL-функцию `get_unseen_users`.
- **Добавление новых админ-команд:** дополните блок `elif` в функции `cmd`.
